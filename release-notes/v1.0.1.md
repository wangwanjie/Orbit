## 新增

- 启动器新增命令帮助页（输入 `?` 或 `help`），以及 `fi`、`if`、`fe`、`fp`、`ts`、`uuid`、`ip` 快捷命令
- `fp` 拷贝访达中选中项目的路径（文件或文件夹，多选时每行一个），未选中时拷贝当前文件夹路径

## 截图与录制

- 窗口截图可以选中访达右键菜单、菜单栏图标弹出的菜单与面板（含控制中心），高亮范围贴合实际可见的菜单
- Orbit 菜单打开时按截图 / 录屏 / GIF 快捷键，菜单会保留在画面中；点击菜单项触发时菜单照常先关闭
- 延时截图的倒计时在菜单展开期间继续
- 录制期间打开的 Orbit 菜单可以录进画面；录制计时项在倒计时阶段就显示，点击即可取消

## 修复

- 访达右键菜单的图标跟随深色 / 浅色外观，与文字颜色一致
- 访达右键菜单弹出缓慢
- macOS 26.7 上启动时主线程卡死，菜单栏图标与控制中心都不出现
- macOS 13–26 上菜单栏布局移动单个项目不生效、全部项目被误判为隐藏
- 控制中心打开过的页面常驻内存，内存占用可达 400MB；区域截图结果长期占用整屏画面的内存
