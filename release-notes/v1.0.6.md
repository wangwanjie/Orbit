这一版对全部模块做了一轮代码审查，集中修复问题并加固涉及删除与管理员权限的部分。

## 安全

- 特权辅助程序：`launchctl` 参数改为白名单校验，只允许启动项管理实际用到的几种形态，拒绝作用于系统自带服务
- 特权辅助程序：以管理员权限删除时不再跟随中途被替换的符号链接，也不跨越挂载点
- 启动项：与系统服务或另一个文件同名的项目，停止 / 禁用 / 删除不再作用到别的服务上
- 重复文件：移到废纸篓前复核文件是否仍与扫描时一致，保留的那一份已变化时整组不动；废纸篓里的文件不再参与查重
- 垃圾清理：目录在扫描后被换成符号链接时拒绝清理；不进入缓存目录里挂载的磁盘映像或网络卷；在访达的确认框里取消清倒废纸篓后不再继续删除
- 应用卸载：扫描残留前核对 App 列表，新装的 App 的数据不再被算作其他 App 的残留；低置信度的特权辅助工具不再默认勾选
- 访达右键“拷贝到 / 移动到”：只直接采用设置里的常用文件夹，其他目标需在选择面板中确认

## 修复

**文件查找**
- 查找窗口显示“找到 N 项”但结果页空白：结果被“隐藏项目 / 包内容 / 废纸篓”开关或上一次留下的过滤文字挡住时，现在会说明原因并可一键全部显示
- 以某个包内部或废纸篓为搜索范围时，结果不再被默认隐藏
- 未开启“提前显示搜索结果”时停止搜索，已找到的结果无处查看
- 从“最近搜索 / 已存储搜索”恢复后查找，保存的视图模式与排序未生效
- 内容搜索遇到命名管道会卡死、按“停止”停不下来
- 全选后移到废纸篓时，文件夹里的结果报“文件不存在”
- 双击表头会打开选中的文件；大于 1 GB 的文件显示成几千 MB
- 结果很多时结果页卡顿（按名称排序不再反复解析路径，搜索进度不再在主线程积压）

**启动器**
- 双击结果行时命令执行两次
- 面板打开时触发命令快捷键，关闭后输入法恢复不回来
- 英文界面搜不到“退出所有 App”
- 脚本启动了后台进程时输出丢失；脚本文件夹被整体替换后不再监听
- 已删除的应用仍留在搜索结果里

**剪贴板**
- 复制后立刻呼出面板并粘贴旧记录，刚复制的内容丢失
- 输入法组字时回车直接粘贴、Esc 关闭面板
- 按住退格清空搜索词后继续删除历史记录
- 右键菜单打开期间列表刷新，操作落到另一条记录上
- 不带编码声明的 HTML 富文本预览成乱码

**截图 / GIF / 录屏**
- 录制中磁盘写满后仍继续计时，停止时才报错
- 文字标注里输入法组字时按 Esc，拼音被当成文字提交
- 文件名模板 `{app}` 在区域 / 窗口截图时总是“Orbit”
- 拔掉显示器后“贴图上一张截图”贴到屏幕外
- 关闭 GIF 预览窗口后临时文件未清理

**窗口管理 / 菜单栏**
- “恢复”把窗口放回已拔掉的显示器位置
- 在无响应的 App 窗口上拖动时 Orbit 卡住数秒
- 关闭“显示器具有单独的空间”时，副屏顶部被当成菜单栏而误触发展开
- 布局编辑器在移动被打断后一直显示“正在移动图标…”

**清理 / 卸载 / 磁盘分析 / 隐私**
- 空类别被计为已选，清理按钮可点但无效
- 展开目录并排除其中一项后，剩余项无法清理
- 清空废纸篓未写入操作记录
- 卸载等待期间改选另一个 App，残留被列在后者名下；本体未删除时显示“已卸载”
- 以 “/” 为范围查重时跳过了整个用户目录；选择 `/private/var`、`/tmp` 等路径时扫描失败
- 隐私清理把“没有需要清理的内容”报告为未完成

**启动项 / 系统调整 / 资源监控**
- 多选操作对不适用的项目也执行并报错
- 异常的 plist（命名管道等）导致列表一直加载
- 打开系统调整页后立刻修改，开关跳回旧状态
- 资源监控启用后的第一个读数不准确，反复开关面板时数值闪成 0

**通用**
- 用文件或链接启动 Orbit 时请求被丢弃
- 快捷键设置：替换冲突的快捷键后另一行仍显示旧值；注册失败的提示不刷新
- 控制中心输入框未按回车就关闭窗口时内容丢失；数值步进到头后回绕
- 操作记录最多只显示 200 条

## 优化

- 5K 屏上微移大选区更顺滑
- 剪贴板缩略图缓存按占用大小封顶，降低常驻内存
- 非窗口拖动时降低辅助功能查询频率
