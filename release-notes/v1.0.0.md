Orbit 的第一个正式版本。

## 功能

- **效率**：启动器（拼音搜索、计算器、网页搜索、脚本命令、翻译与编解码工具）、窗口管理（26 个动作、边缘吸附）、剪贴板历史、菜单栏图标整理、资源监控
- **截图与录制**：区域 / 窗口 / 全屏截图与标注、贴图、文字识别，GIF 录制，录屏（系统声音与麦克风）
- **文件**：访达右键菜单增强、OpenIn 终端 / 编辑器小程序、不建索引的文件查找、磁盘占用分析与重复文件查找
- **系统**：启动项管理、应用卸载与残留清理、垃圾清理（120 条规则）、隐私清理、系统维护、系统微调

## 其他

- 界面支持简体中文、繁體中文与 English，应用内随时切换，无需重启
- 内置自动更新：每天检查一次，只下载与本机芯片匹配的版本
- 设置可以导出为 `.orbitconfig` 文件，在其他 Mac 上双击还原
- 分别提供 Apple 芯片与 Intel 芯片安装包，需要 macOS 13.0 或更高版本
